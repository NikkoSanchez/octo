# Octo artwork

`octo-logo.png` is the original 1254 × 1254 artwork supplied by the project owner: a coral octopus wearing navy sunglasses on a cream background. Preserve this source when updating derived icon sizes.

`../Assets.xcassets/AppIcon.appiconset` contains the macOS 1× and 2× icon representations (16, 32, 128, 256 and 512 points), resized from the original with macOS `sips`. The Xcode app target compiles this catalog and selects `AppIcon` in both Debug and Release. No artwork is regenerated or recolored.
